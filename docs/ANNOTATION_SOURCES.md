## 3. 主源詳解：kanripo/KR2e0003

### 3.1 這是什麼

漢籍リポジトリ（Kanripo）**KR2e0003** = 四部叢刊本《戰國策校注》，元·吳師道撰。
倉庫 `Readme.org` 自述（逐字）：

```
#+TITLE: 戰國策 / SBCK
* 版本
 |      SBCK|【四部叢刊】  |
 |       WYG|【四庫全書・文淵閣】|
```

檔名 `SB02n0044-001戰國策校注-卷第一` 進一步確認底本為四部叢刊。

### 3.2 為什麼它同時含「鮑彪注」與「吳師道補正」

KR2e0005（四庫本）卷首《提要》逐字給出了這部書的體例：

```
戰國䇿舊有髙誘注宋紹興間縉雲鮑彪病其闕略重為之注而復為改定其次第
師道又以鮑彪注為未善又取剡川姚宏之注與彪注叅校而雜引諸書考證之
其書一仍彪注之舊而每條之下凡增其所闕者謂之補凡糾其所失者謂之正
各以補曰正曰別之
```

→ **結構定義**：每條之下 = 鮑彪注（無標記）+ 吳師道 `補曰` + 吳師道 `正曰`。
→ **高誘注已被鮑彪「重為之注」取代**，這正是 #1/#2/#3 全數 `高誘` 出現 0 次的原因。

### 3.3 鍵：注文被壓平成括號

原始文本的排版是「大字正文 + 雙行小字夾注」，數字化時**小字被塞進圓括號，原雙行用 `/` 分隔**，`¶` 為行末，`<pb:…>` 為葉碼。逐字原文（`_001`，東周策·嚴氏爲賊章）：

```
嚴氏爲賊(嚴仲殺韓相傀列侯三年書殺俠累是也/殺人不以道曰賊於此爲五年正曰韓策)¶
(陽堅此作竪字有訛索隱曰紀年韓山堅賊其君/哀侯韓山堅即韓嚴非嚴遂使聶政殺俠累事也)¶
(說見上/及韓策)而陽竪與焉(鴻烈人間訓注竪/小使也韓策名堅)道周(出亡/過周)¶
```

去掉 `/` 與葉碼後的**還原結果**（實測可得）：

```
嚴氏爲賊【嚴仲殺韓相傀列侯三年書殺俠累是也殺人不以道曰賊於此爲五年正曰韓策
陽堅此作竪字有訛索隱曰紀年韓山堅賊其君哀侯韓山堅即韓嚴非嚴遂使聶政殺俠累事也
說見上及韓策】而陽竪與焉【鴻烈人間訓注竪小使也韓策名堅】道周【出亡過周】
```

### 3.4 解析規則（可直接寫進抓取器）

1. 讀檔，丟棄 `#+…` 頭部與 `<pb:KR2e0003_SBCK_\d+-\d+[ab]>¶` 葉碼。
2. `¶` → 換行；行首全角縮進 `　` 為版式殘留，可保留作「段」線索。
3. 掃描圓括號：**第一個 `(` 之前的連續文本 = 正文（鮑彪改定本）**；括號內 = 注文。
4. 括號內按 `/` 去折行後，用 `正曰` / `補曰` / `彪謂` / `彪曰` 切分歸屬：
   - `正曰` 之後 → `{source:"吳師道·正"}`
   - `補曰` 之後 → `{source:"吳師道·補"}`
   - `彪謂`/`彪曰` 及其後 → `{source:"鮑彪"}`
   - 其餘（無標記的前段）→ `{source:"鮑彪"}`（依 §3.2 體例）
5. ⚠️ **一個注塊可能被葉碼切斷**：實測 `_001` 末尾出現 `(莫反正曰/適專主也`（未閉合），是因為下一葉換頁。**必須先按葉碼切段、跨頁拼接後再解析**，否則會漏注。
6. ⚠️ 全書範圍內括號總數配平（見 3.5），但**局部不配平是常態**，不要用「配平」做校驗，要用「跨頁拼接」做校驗。

## 5. 字詞訓釋（glossary）的兩條路

### 5.1 主路：從注文反抽（零外部依賴）

注文本身就是訓釋，句式高度規整。實測樣本（`KR2e0003_003`，蘇秦章）：

```
詘敵國(詘服/也)           → 詘 = 服也
制海内子元元(元/善)(也民之類/善故稱元) → 元元 = 善也，民之類善故稱元
皆惛於教(惛不/明也)        → 惛 = 不明也
溺於辭(溺謂為/所冐没)      → 溺 = 謂為所冐没
黒貂之裘敝(貂䑕屬大而黄/黑出丁零國) → 貂 = 鼠屬，大而黃黑，出丁零國
資用乏絶(資貨/也)          → 資 = 貨也
```

抽取規則：`(head)(X，Y也)` / `(head)(X 猶 Y)` / `(head)(X 謂 Y)`。
實測在 866 KB 樣本中，僅用緊正則 `\([^()]{0,80}也[/）]` 即命中 **153** 條；放寬後可覆蓋大部分「X，Y也」型注。

⚠️ **anchor 精度風險**：注緊跟在被注詞後，但被注對象可能是**單字、雙字詞或整句**（如 `嚴氏爲賊(…)` 注的是整章題）。用「括號前 N 字」硬切會產生錯掛。建議只收「括號前 1–4 字且注文以『也/猶/謂』收尾」的高置信子集，其餘進存疑清單。

### 5.2 輔路：漢典 zdic.net（複詞有書證，直引《戰國策》）

`https://www.zdic.net/hans/合從` → **200 / 25,785 B / text/html; charset=utf-8**

纵向的连接。书证：日夜合离，以成文章。以能合从，又善连衡。——《荀子·赋》

## 6. 落到 SCHEMA 上

```json
{
  "id": "dongzhou-01-p0001",
  "text": "嚴氏爲賊，而陽竪與焉，道周。",
  "annotations": [
    { "source": "鮑彪",     "text": "嚴仲殺韓相傀，列侯三年書殺俠累是也。殺人不以道曰賊，於此爲五年。" },
    { "source": "吴师道正", "text": "韓策陽堅，此作竪，字有訛。索隱曰：紀年韓山堅賊其君哀侯…非嚴遂使聶政殺俠累事也。" }
  ],
  "glossary": [
    { "term": "陽竪", "pinyin": null, "gloss": "鴻烈人間訓注：竪，小使也。韓策名堅。" }
  ]
}
```

- `source` 取值域收斂為三：`鲍彪` / `吴师道补` / `吴师道正`（高誘留待後補，勿偽造）。
- `edition` 取值域收斂為二：`四部叢刊`（KR2e0003，底本）/ `四庫全書`（KR2e0005，補注）。
  底本注不寫該鍵，**缺省即四部叢刊**；只有四庫全書本補入的注顯式寫 `四庫全書`。
