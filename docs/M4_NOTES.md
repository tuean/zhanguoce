# M4 · 謀略層（篇章內的遊說結構）實作說明

本層只做一件事：把「誰對誰說」與「原文裡看得見的修辭手段」標出來，每一條都能回到原文那一段、那幾個字。
不判斷謀略高下，不推斷說話人的用心，不做任何 AI 預生成（Q5 = C：只用實時 API 追問）。
原則沿用全書：寧可標得少，不許標錯——標錯會讓讀者記住一個錯誤的謀略判斷，比沒有更糟。

## 1. 產物與資料流

    tools/strategy_lexicon.py    六類手段詞表（每條 pattern 都寫了 why 與 rejects）
    tools/build_strategy.py      規則抽取器：讀 volumes/**.json 原文 + entities/people.json
    tools/validate_strategy.py   獨立校驗器：只信 volumes/ 原文，不信生成器的自述
    data/zhanguoce/strategy/chapters.json   生成物（497 章全覆蓋，空章也保留）
    crates/zgc-core/src/strategy.rs         型別 + load + fail-fast
    crates/zgc-app/src/pages.rs             章頁「謀略結構」區塊（<details> 折疊，零 JS）

再生產：

    python3 tools/build_strategy.py
    python3 tools/validate_strategy.py

## 2. schema（schemaVersion 1）

    { schemaVersion, bookId, deviceKinds: [{kind, rationale}],
      chapters: [{ chapterId, turns: [...], devices: [...], stats: {turns, devices} }],
      unresolvedTurns: [{ chapterId, p, turnIndex, field, reason }] }

turn：{ index, p, speaker, speakerId, addressee, addresseeId, marker, offset, text }

- marker 與 offset 是「謂」在該段原文（Unicode scalar 偏移，非位元組）的位置；text 是含 marker 的那一小段原文，marker 必須落在 text 內。
- speaker / addressee 為 null 表示未識別，一律寫 null，不寫空字串；每一處 null 都在 unresolvedTurns 裡有一條對應記錄（field = speaker 或 addressee，reason 為固定詞彙）。
- addressee 可以「有字無 id」：原文寫「楚王」而人物表沒有楚王時，addressee 保留「楚王」（讀者可複核），addresseeId 為 null 並記 unresolved——文字可查，身分不猜。

device：{ kind, p, offset, matched, len }。校驗器回原文驗證 text[offset..offset+len] == matched。

### 類別命名：資料用繁體，任務書用簡體

| 資料（kind） | 任務書 | rationale |
| --- | --- | --- |
| 類比譬喻 | 类比譬喻 | 用另一件事物比擬當前事理，以彼證此 |
| 史例 | 史例 | 援引前代人事作為當下判斷的依據 |
| 利害威嚇 | 利害威吓 | 指出不行此計必致的危亡後果 |
| 利誘好處 | 利诱好处 | 指出行此計可得的利益 |
| 反問詰難 | 反问诘难 | 以反詰句式代替斷言 |
| 引書引諺 | 引书引谚 | 引詩書或諺語作權威 |

## 3. 輪次規則（只用「謂…曰」與人物表，不靠語感）

1. 在段落原文裡找「謂」；若前一字為 所／何／不／可／無／是（所謂、何謂、可謂、不謂、無謂、是謂），不是「A 謂 B 曰」，跳過。
2. 取「謂」後 14 字內第一個「曰」；中間區間必須非空、≤10 字、不含標點（，。：！？「」『』；、）。
3. 說話人：把「謂」之前的文字與人物表全部 name/aliases 做結束於此的最長匹配（同一位置取最長字形）。
4. 受話人：把「謂」與「曰」之間的文字與人物表別名做完全相等匹配（不做模糊、不做前綴）。
5. 兩側都填不上 → 整條丟棄（避免把「或謂…」「客謂…」這種無主語殘句變成假輪次）；只填上一側 → 保留，另一側 null 並記 unresolved。
6. 同一段允許 0..n 條輪次，按 (段落序, offset) 排序，index 從 0 連續。

四種 reason：speaker-not-in-entities（不在人物表內）、speaker-anonymous（原文只說「或」「客」）、addressee-not-in-entities、addressee-anonymous。頁面把它們翻成人話（zgc_core::strategy_reason_text）。

實測：全書「謂」在正文 552 次（與任務書基線 246 次口徑不同：這裡含所有段落、含所謂／何謂等前綴；剔前綴與殘句後候選 418 條），保留 169 條輪次、分佈 153 章；說話人可指認 87 條、受話人可指認 100 條、雙方皆可 18 章（3.6%）；unresolved 151 條。
不指望填滿：說客大量不在 176 人物表內，未識別就寫未識別。
## 4. 詞表：30 條 pattern，六類

詞表在 tools/strategy_lexicon.py，每條 entry 三個欄位：pattern、why（為何這個字串在此語境裡就是該手段）、rejects（為何鄰近的更寬寫法被拒）。此處只列結論性依據：

| kind | pattern 數 | 代表 pattern | 為何不會誤報（摘要） |
| --- | --- | --- | --- |
| 類比譬喻 | 1 | 譬（可帶 如／猶／若） | 「譬」在先秦只有「比方」一義，12 次全是類比 |
| 史例 | 4 | 昔者／古者／曩者／往者 | 皆為固定追述開頭；前置 guard 排除「自今以往者」 |
| 利害威嚇 | 5 | 必危／危矣／必亡／禍必／大禍 | 都是「必＋後果」或判斷句收尾，逐條可複核 |
| 利誘好處 | 5 | 大利／王業／霸王之業／帝業／何求而不得 | 皆為對聽者的利益斷言；帝業 0 命中屬預留 |
| 反問詰難 | 8 | 豈＋十個反詰副詞…乎哉邪耶／何…之有／何以…爲／不亦…乎／獨…乎哉／惡得／安能／安得 | 都是帶句末語氣詞的固定框架，不是單字 |
| 引書引諺 | 7 | 詩曰／詩云／易曰／諺曰／周書曰／鄙語曰／句讀後的語曰 | 引用動詞＋書名或語體，後接引文 |

## 8. 內核 fail-fast

zgc-core::Strategy::load 讀檔後逐條回原文驗證，任何一條不成立就整體報錯（不回退、不跳過）：

1. schemaVersion 必須是 1；bookId 必須等於書；deviceKinds 非空且不重複。
2. 章必須存在且唯一；全書 497 章必須一艘不漏；章序等於書序。
3. turn.index 等於其在陣列中的位置；同章 turns 按 (段落, offset) 排序；同段同偏移不得重複。
4. turn.p 必須屬於該章；marker/offset 切片必須等於 marker；text 必須是該段原文的子串且含 marker。
5. speaker 與 speakerId 必須同為 null 或同有值；addressee 為 null 時 id 必須 null。
6. speakerId/addresseeId 必須存在於人物表，且該側文字必須是該實體 name/aliases 之一。
7. device.kind 必須已在 deviceKinds 宣告；len>0 且等於 matched 的字元數；offset+len 不越界；切片等於 matched；同段手段不重疊。
8. stats 必須等於實際陣列長度。
9. unresolvedTurns 的每一條都必須對應真實的 turn、p 相符、該欄位確實為 null；且「null 欄位集合」與 unresolvedTurns 完全相等（多了少了都報錯）。

缺檔（ErrorKind::NotFound）→ Ok(Strategy::empty())，服務照常起，章頁不顯示區塊；其餘 I/O 錯誤或任何不一致 → 硬失敗並打印中文提示。
校驗器 tools/validate_strategy.py 是同一組斷言的獨立實作（只信 volumes/ 原文），17 例故意污染的假資料全部 exit=1。

## 9. 頁面（章頁 = 段落 0）

「謀略結構」插在「系年」（本章繫年）之後，<details> 折疊，零 JavaScript。三態：

1. 有輪次／有手段：summary 顯示「N 輪遊說 · M 處手段」；輪次表四列（#／說話人／受話人／章文），person 有 id 時連結 /entity?id=…，無 id 時顯示原文稱謂加「（未識別）」與 title；章文連結跳到該段。
2. 只有手段：只顯示手段分組。
3. 兩者皆無：一行「本章未檢出游說標記」，不渲染空表格。

手段按 kind 分組，每條給 /read?p=<段id>&hl=<offset>,<len>，回原文並高亮。

### hl 與既有語義

hl 原本只認落在實體 span 上的偏移；為 device 擴充時沒有放開任意偏移，而是新增一條：hl 必須精確等於該段某個已記錄 device 的 (offset,len)，否則仍然靜默忽略。既有測試（hl=0,0／2,1／999,1／-1,2 皆不得出 mark）照舊通過；實體命中優先於 device 命中。

## 11. 已知邊界

- 「謂」的 552 次與任務書 246 次口徑不同：此處統計所有段落，含所謂／何謂／可謂等前綴字串；剔除後才是候選 418 條。
- 「A 謂 B 曰」之外還有「A 說 B」「A 對 B 曰」「A 為 B 謂 C 曰」等引入方式，本層未收（收了就必須靠語感，違反可複核原則）。
- 手段只判字面是否為該修辭框架，不判它用得對不對、有沒有說服力。
